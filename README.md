# dotsys — 배포 저장소

**이 저장소는 설치 파일 배포 전용입니다. 소스 코드는 여기에 없습니다.**

dotsys 는 Windows·Android 용 기록 앱입니다. 알림으로 붙잡지 않고, 연속 기록으로
다그치지 않습니다. 기록은 서버가 아니라 사용자의 기기에 남습니다.

- 홈페이지 · 라이선스 키 발급: https://dotsys.app
- 자주 묻는 질문: https://dotsys.app/faq
- 최신 설치 파일: [Releases](../../releases/latest)

## 왜 저장소가 공개인가

GitHub Release 의 파일을 **로그인 없이** 내려받으려면 저장소가 public 이어야 합니다.
그래서 배포용 저장소만 공개로 두고, 제품 소스는 비공개로 유지합니다.

## 설치 시 경고

현재 알파 빌드는 코드 서명 인증서를 아직 붙이지 않았습니다. Windows SmartScreen 이
"PC를 보호했습니다" 경고를 띄우면 `추가 정보` → `실행` 을 눌러 진행하세요.
